# CK_PB1 v1.1.0

آپدیت بزرگ **CK_PB1** — ۱۲ ماژول جدید، Fly سه‌حالته، God Bridge بدون کلیک و منوی بازطراحی‌شده.

## فایل‌های این Release

| فایل | توضیح |
| --- | --- |
| `CK_PB1-v1.1.0-Setup.exe` | نصب‌کننده ویندوز (Shortcuts + Java 17 داخلی + Uninstaller) |
| `CK_PB1-Client-1.1.0+mc1.20.1.jar` | کلاینت (Fabric mod) — برای نصب دستی در پوشه `mods` |
| `CK_PB1-Launcher-1.1.0.jar` | Launcher — برای اجرای مستقل (نیازمند Java 17) |
| `README.md` | مستندات کامل |
| `CHANGELOG.md` | تغییرات نسخه |

## جدید در این نسخه

### ⚔️ Legit Aura (کیل‌اورای لگیت 1.8.9)
روتیشن نرم انسانی با Jitter، CPS تصادفی، محدوده FOV، عدم حمله از پشت دیوار، سوئینگ فقط وقتی کراس‌هیر نزدیک هدف است و Micro-Pause — برای تک‌پلیر و سرورهای خصوصی/تست.

### 🌉 God Bridge (0 CPS)
حالت جدید Bridge Assistant: پل‌زدن خودکار با سرعت کامل بدون حتی یک کلیک. فقط راه برو عقب!

### 🧱 Scaffold
بلوک‌گذاری خودکار زیر پا هنگام دویدن — حالت Normal و Tower.

### ✈️ Fly سه‌حالته
- **Creative** — پرواز کلاسیک
- **Jetpack** — بالا رفتن نرم با سرعت (بدون فلگ‌های پرواز)
- **Glide** — سرازیر شدن نرم
- **Anti-Kick** — برای چک‌های Floating ونیلا

### 👁️ ESP / Tracers / Trajectories
هایلایت بازیکنان، ماب‌ها، آیتم‌ها و تخت‌ها از پشت دیوار + خطوط نشانه + پیش‌بینی مسیر پرتابه‌ها با نشانگر فرود.

### 💬 Chat Translator
ترجمه خودکار پیام‌های چت به فارسی/انگلیسی/عربی/ترکی/فرانسوی/آلمانی/روسی/اسپانیایی.

### 🧰 ابزارهای جدید
Anti AFK، Auto Respawn، No Slow، Fast Place، Spider، Auto Sprint

### 📊 Module List HUD
Array List کلاسیک با گرادیان رنگی — همه‌ی ماژول‌های فعال را نشان می‌دهد.

### 🎨 منوی بازطراحی‌شده
گرادیان هدر، رنگ اختصاصی هر دسته، نوار وضعیت پایین، شمارنده ماژول‌های فعال و جستجوی فوری با تایپ.

---

⚠️ ماژول‌های PvP و اتوماسیون فقط برای **تک‌پلیر و سرورهای خصوصی/تست** هستند. هیچ کلاینتی نمی‌تواند تضمین کند که هر آنتی‌چیت سمت سرور آن را نپذیرد — تصمیم نهایی همیشه با سرور است.

**ارتقای از v1.0.0:** نصب‌کننده جدید را اجرا کنید — مسیر و تنظیمات قبلی حفظ می‌شود.
