# CK_PB1 v1.0.0

اولین نسخه رسمی کلاینت **CK_PB1** برای Minecraft Java 1.20.1 (Fabric).

## فایل‌های این Release

| فایل | توضیح |
| --- | --- |
| `CK_PB1-v1.0.0-Setup.exe` | نصب‌کننده ویندوز (Desktop/Start Menu Shortcuts + Java 17 داخلی + Uninstaller) |
| `CK_PB1-Client-1.0.0+mc1.20.1.jar` | کلاینت (Fabric mod) — برای نصب دستی در پوشه `mods` |
| `CK_PB1-Launcher-1.0.0.jar` | Launcher — برای اجرای مستقل (نیازمند Java 17) |
| `README.md` | مستندات کامل |
| `CHANGELOG.md` | تغییرات نسخه |

## نصب سریع

1. `CK_PB1-v1.0.0-Setup.exe` را دانلود و اجرا کنید.
2. **CK_PB1** را از میانبر Desktop/Start Menu باز کنید.
3. نام کاربری، RAM و پوشه بازی را تنظیم و **Launch** بزنید — بقیه خودکار است.

## نکات

* Click GUI با `RShift`، HUD Editor با `.ck hud`، لیست دستورها با `.ck help`
* قابلیت‌های PvP/Automation فقط برای Singleplayer و سرورهای خصوصی/تستی
* برای آپدیت‌های بعدی، Launcher به‌صورت خودکار آخرین Release را بررسی می‌کند
  و پیام «آپدیت جدید در دسترس است» را نشان می‌دهد.
